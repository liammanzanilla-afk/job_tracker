# AI Usage Documentation

## Tools Used

- ChatGPT was used to assist with developing the Flask application,
  MySQL database connections, HTML templates, and CSS styling.
- ChatGPT was also used to understand CRUD functionality and develop
  the job skills matching algorithm.

## Key Prompts

1. "Help me create a Flask application that connects to a MySQL database."
2. "Create CRUD functionality for companies, jobs, applications,
   and contacts using Flask and MySQL."
3. "Help me create HTML templates for a job application tracker."
4. "Create a Python function that compares user skills with job
   requirements and calculates a match percentage."
5. "Help me debug Flask routes and MySQL database connection errors."
6. "Help me create a professional dashboard using HTML, CSS, and Bootstrap."

## What Worked Well

- ChatGPT helped create the basic Flask application structure.
- AI assistance made it easier to understand SQL queries and
  foreign key relationships.
- AI helped develop reusable CRUD routes for the four database tables.
- AI helped create the job matching percentage calculation.
- AI helped organize the project files and documentation.

## What I Changed

- Customized the database connection to use my local MySQL credentials.
- Used the database schema required by my course project.
- Modified the HTML pages to match my application.
- Tested the SQL queries against my actual database.
- Used sample company, job, application, and contact records to
  test the application.
- Reviewed and tested the generated code and made corrections
  when necessary.

## Lessons Learned

- AI can help speed up software development, especially when
  creating repetitive code.
- Generated code should always be reviewed and tested.
- I learned how Flask routes communicate with HTML templates.
- I learned how Python connects to MySQL.
- I learned how primary keys and foreign keys connect database tables.
- I learned how JSON data can store job requirements and interview information.
- I learned how to calculate job match percentages using Python.
- AI is a helpful development assistant, but the developer is
  responsible for understanding and verifying the final application.

## Conclusion

ChatGPT was used as a development assistant throughout this project.
The generated code was customized and tested as part of building
my Job Application Tracker.
